# Emissive Texture（発光テクスチャMod）

リソースパックに `*_e.png` を置くだけで、そのテクスチャの**塗った部分だけ**を暗闇でも光らせるFabricクライアントModです。設定ファイルは要りません。

## 発光テクスチャ（Emissive Texture）とは

Minecraftのテクスチャは、周囲の明るさ（光レベル）に応じて暗く描かれます。夜の洞窟では、どんなに明るい色のテクスチャも暗く沈んでしまいます。

「発光テクスチャ」は、テクスチャの一部だけを、周囲の明るさに関係なく**最大の明るさ**で描く仕組みです。光るのは指定したピクセルだけで、残りは今までどおり暗くなるので、暗闇の中でも光る部分だけが浮かび上がります。

このModは、光らせたいピクセルを描いた画像を、通常のテクスチャと同じ名前に `_e` を付けて置くだけで、自動的にその仕組みを有効にします。


## 用途

- 光る鉱石、溶岩の割れ目、魔法陣、ルーン文字など
- 暗闇で目だけが光るモブ、光る模様を持つエンティティ
- 光る剣、杖、魔法のアイテム
- ネオン看板、ランプ、機械のインジケーターなど、光る部分を持つブロック
- 配布用リソースパックやサーバー専用パックでの演出

Modの追加ブロックやアイテムも、名前空間を問わず自動で対象になります。


## 使い方

### 1. Modを導入する

（省略）

### 2. リソースパックを作る

光らせたいテクスチャ `名前.png` と同じフォルダに、`名前_e.png` を置きます。

```text
resourcepack/
├── pack.mcmeta
└── assets/
    └── minecraft/
        └── textures/
            ├── item/
            │   ├── diamond_sword.png      ← 通常のテクスチャ
            │   └── diamond_sword_e.png    ← 発光テクスチャ
            ├── block/
            │   ├── diamond_ore.png
            │   └── diamond_ore_e.png
            └── entity/
                └── zombie/
                    ├── zombie.png
                    └── zombie_e.png
```

Modの追加アイテムも同じ方法です。

```text
assets/mymod/textures/item/test.png
assets/mymod/textures/item/test_e.png
```

### 3. 発光テクスチャを描く

`_e.png` は、光らせたいピクセルだけを描きます。

- **色は `_e.png` のRGBがそのまま発光色になります。** 通常のテクスチャの色は描画されません。赤なら赤く、白なら白く光ります。
- **透明なピクセルは光りません。** 光らせない部分は、アルファを0（完全に透明）にしてください。
- **半透明のピクセルは、その透明度に応じて弱く光ります。**
- **通常のテクスチャと同じ大きさにしてください。** 16×16なら `_e.png` も16×16です。
- アニメーションテクスチャは、`_e.png` も同じフレーム構成にしてください。


### 4. ゲームで確認する

1. リソースパックを有効にします。
2. 暗い場所（夜や洞窟）で、対象のアイテム、ブロック、モブを見ます。
3. `_e.png` を追加、変更、削除したあとは、`F3 + T` でリソースを再読み込みします。検出結果は、そのたびに自動で作り直されます。


## 仕組みの概要

- **アイテム、ブロック**：モデルを読み込むときに、`_e` が存在するクアッド（面）ごとに、同じ位置に `_e` のスプライトを貼った面を追加します。追加した面は、最大の明るさ（発光レベル15）で描かれます。
- **BlockEntity、エンティティ**：元のモデルを描いた直後に、同じモデルを `_e` テクスチャで、最大の明るさでもう一度描きます。`_e` の透明な部分は描かれないので、光るのは `_e` のピクセルだけです。


## うまく光らないとき

1. **`latest.log` に `Detected N emissive texture(s)` が出ているか確認する。**
   - 出ていない、または `N` が0の場合：ファイル名が `名前_e.png` になっているか、通常の `名前.png` が同じフォルダにあるかを確認してください。通常のテクスチャがない `_e.png` は無視されます。
   - `N` が1以上の場合：検出はできています。次に進んでください。
2. **`F3 + T` で再読み込みしたか確認する。**
3. **`_e.png` の大きさが通常のテクスチャと同じか確認する。**
4. **`_e.png` の光らせたい部分のアルファが0になっていないか確認する。**
5. **`textures/item/` や `textures/block/` 以外に置いていないか確認する。**
6. **他のMod（特に描画系）を外して試す。**

それでも解決しない場合は、`latest.log` と、`_e.png` を置いたフォルダ構成を添えて報告してください。
